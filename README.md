## Solarxy

A cross-platform 3D model viewer, validator, and browser-based node modeler, built in Rust and wgpu (WebGPU). Inspect and validate models in a native real-time viewer, analyze them from the terminal for CI, or build geometry parametrically in the browser on a node graph. Three surfaces, one shared Rust core.

- **Viewer.** A native, real-time PBR viewer with split viewports and a debugger's inspection overlays: normals, UV overlap, texel density, overdraw, material ID, and a validation pass.
- **CLI.** A terminal analyzer that runs the same checks in CI and emits SARIF, JUnit, or TAP, so broken geometry never ships.
- **Web.** The viewer, validator, and review tools in the browser on WebGPU, plus a node-based parametric modeler with 58 node types. Nothing installs, nothing uploads, every byte stays on your machine.

Solarxy is the tool I always wanted on the desk between receiving an asset and trusting it. It is a team of one and an AI-first build: AI did most of the typing, I owned the judgment, and years in 3D pipelines are what kept it honest.
